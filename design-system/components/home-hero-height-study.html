Homepage · Hero card height study

The matchbook card is 994px tall at 1440, so it runs 182px past the fold on a 900px viewport. Target is 750px. Randall's brief: reduce the space between elements, widen the subhead and intro, shrink the logo, and keep the mascot as close to its current size as possible.

The one structural change. Today the copy column is width:fit-content, and the subhead and intro both use a width:0; min-width:100% trick that removes them from intrinsic sizing. The result is that the text column is exactly as wide as the wordmark renders (569px). Shrinking the logo therefore narrows the copy, which is the opposite of what we want. Option B gives the column an explicit width so the two can move independently.

r2 (2026-07-30). Rule halved to 415px and centred, subhead set at a 460px measure so both lines run full, intro margins brought in to a 560px measure so it settles at three lines, mascot down 10%, both signs down 20%. B now measures 731px.

The wordmark shown here is the correct registration and is a separate, already-shipped fix. Production was rendering the base in ink, not teal, because a broad theme rule (.publicLandingHeroCopy h1, specificity 0-1-1) outranked .publicLandingWordmark's own teal at 0-1-0, even though both were !important. That selector has been removed, so the teal + tomato off-registration overprint is live. Nothing else in this card is deployed yet.
